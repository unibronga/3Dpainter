# Как устроен инструмент покраски

> Технический разбор: архитектура, ключевые решения и грабли.
> Общее описание проекта — [README.ru.md](../README.ru.md),
> справка пользователю — [СПРАВКА.md](../СПРАВКА.md).

Браузерный инструмент: открыть готовую low-poly модель, **вращать её и красить
кистью прямо по поверхности**. Отдельный шаг поверх готовой модели — пайплайн
моделиста он не трогает, модель по-прежнему сдаётся плоскими материалами.

**Как этим пользоваться — [СПРАВКА.md](../СПРАВКА.md)** или **F1** в самой
программе. Здесь — как оно устроено и почему сделано так.

Решения владельца от 20.09.2026: носитель — **браузер на three.js**; набор
инструментов **полноценный** (UV-карты, кисти, заливки, маски); **как результат
возвращается в проект и в GLB — решаем после прототипа.**

## Запуск

**В браузере:**

```bash
npm install && npm run dev
```

Откроется на `http://localhost:5273`. Стартует с демо-хижиной — можно красить
сразу, без своей модели.

**Как обычное приложение** (окно Electron, собирает и запускает):

```bash
npm run desktop
```

Оболочка в `electron/main.cjs` — обычное окно Chromium без доступа к Node:
инструменту он не нужен, и страница внутри ровно та же, что в браузере. Своё
хранилище настроек, чтобы они не мешались с браузерными. Дымовая проверка
сборки — `PAINT_TOOL_SELFTEST=1 npx electron .`: поднимает окно, убеждается,
что инструмент завёлся и модель собралась, и выходит.

**Установщик:**

```bash
npm run dist
```

Собирает значок, страницу и упаковывает всё в `release/`:
`3DPainter-<версия>-arm64.dmg` (образ для установки перетаскиванием) и
`.zip` той же сборки. Настройки — в `electron-builder.yml`; в приложение
кладутся только `dist/` и `electron/`, потому что Vite уже вшил в `dist`
всё нужное, и второй раз тянуть библиотеки незачем.

🔴 **Приложение не подписано** — сертификата разработчика у проекта нет.
При первом запуске macOS скажет, что не может проверить разработчика. Обойти:
правой кнопкой по значку → «Открыть» → «Открыть», либо один раз снять карантин:

```bash
xattr -dr com.apple.quarantine /Applications/3DPainter.app
```

Сборка под Windows и Linux в `electron-builder.yml` описана, но делается
только на своей системе: под macOS собирается macOS.

Значок рисуется кодом — `npm run icon` пересобирает
`build/icon.png` из `scripts/make-icon.mjs`. Готовой картинки в проекте нет
намеренно: значок можно поправить строкой, и он не «приходит ниоткуда».

Модель загружается кнопкой «Открыть GLB…» или перетаскиванием `.glb` во вьюпорт.

## Управление

| Действие | Как |
|---|---|
| Инструмент | **ЛКМ** |
| Вращать | **ПКМ** |
| Перемещать | **пробел + ЛКМ** (или средняя кнопка) |
| Зум | **колесо** |
| Размер кисти | **[** и **]** |
| Инструменты | **B** кисть · **E** ластик · **I** пипетка · **F** заливка граней · **G** заливка острова · **M** маска |
| Виды | **1** спереди · **2** сзади · **3** слева · **4** справа · **6** сверху · **7** снизу · **0** 3/4 |
| Куб ориентации | **протяжка** — вращать камеру · **щелчок** по грани, ребру или углу — встать на этот вид |
| Проекция | **5** — перспектива ↔ ортография |
| Вписать в кадр | **Home** |
| Развёртка на полэкрана | **U** |
| Скрыть все панели | **Tab** |
| Отмена / возврат | **Cmd+Z** / **Cmd+Shift+Z** |

В развёртке: **ЛКМ** — инструмент, **ПКМ** или пробел — перемещать полотно,
**колесо** — зум вокруг курсора.

## Инструменты

- **Кисть** — размер задаётся в долях габарита модели, подпись показывает его в
  сантиметрах: масштаб в проекте метровый.
- **Ластик** — снимает краску со слоя до прозрачности, подложка проступает.
- **Пипетка** — берёт цвет с итоговой текстуры под курсором.
- **Заливка связанных граней** — разливается от грани по форме, переходя ребро
  только если излом меньше порога. «Залей крышу» не перетекает на стену.
- **Заливка UV-острова** — заливает остров развёртки целиком, шов её держит.
- **Залить слой** — весь слой активного меша.
- **Маска** — кисть по маске слоя: по умолчанию скрывает, **Shift** возвращает.
- **Прямоугольник** и **круг** — заливкой или контуром заданной толщины,
  **Shift** делает стороны равными. Тянутся мышью, рамка видна по ходу.
- **Текст** — надпись из панели, кегль ползунком или высотой протяжки.

Фигуры и текст печатаются **проекцией на экран**: для каждого текселя берётся
его точка на поверхности, проецируется в кадр и проверяется по трафарету.
Поэтому прямоугольник остаётся прямоугольником в кадре, как бы ни была изогнута
поверхность под ним, и ложится сразу на стену и крышу. Отвёрнутые от камеры
грани не печатаются.

**Альфа** в палитре задаёт, насколько плотно краска ложится за один мазок;
внутри мазка перекрытия не копятся, так что медленное движение не темнит след.

### Окно кистей

Кнопка в заголовке секции «Кисть». Шестнадцать готовых кистей — жёсткая и
мягкая круглые, маркер, тушь, карандаш, аэрограф, пастель, сухая кисть, мел,
губка, брызги, царапины, квадратная, плоский резец, мягкий квадрат,
штукатурка — и настройки: размер, жёсткость, нажим, **зерно**, **интервал**,
**разброс**, форма (круг или квадрат).

Образцы в списке и большой образец сверху рисуются **той же математикой**, что
и настоящая кисть: тем же спадом и тем же зерном. Большой образец
перерисовывается на каждое движение ползунка — настройку видно сразу, а не
после первого мазка.

Зерно привязано к текселю, а не к отпечатку: за один мазок тексель задевается
десятки раз, и случайное число на каждый отпечаток давало бы мерцание вместо
фактуры.

## Материал

Кисть несёт **материал целиком**: цвет плюс поверхность (шероховатость и
металл). Поверхность ложится по тем же текселям, что и краска, — «покрасить
железом» делает железной только закрашенную область, а не модель целиком.

Материал — это **цвет, узор, поверхность и прозрачность**. Боковая панель
показывает его шаром, а не полем цвета: цвет здесь лишь одно свойство из
четырёх. Быстрая палитра под шаром — обычная краска: цвет, матовая
поверхность, без узора.

Хранится это второй картой: шероховатость в зелёном канале, металл в синем —
стандартная упаковка, которую three.js читает напрямую. Прозрачность живёт в
альфе цветовой карты. При сохранении карта материала выгружается отдельным
файлом `<имя>_material.png`, но только если по ней действительно красили.

**Прозрачность** включается на меше сама, как только ею покрасили, и вместе с
ней включается двусторонняя отрисовка: сквозь стекло должна быть видна
изнанка модели, иначе поворот не показывает ничего нового. Пока прозрачного
нет, меш рисуется обычным непрозрачным проходом — платить за сортировку без
нужды незачем.

### Своя текстура

В списке узоров последняя карточка — **своя картинка**. Загружается с диска,
повторяется по развёртке нужное число раз («Повтор»), и кисть красит уже ею.
Большие снимки ужимаются до 1024 по большей стороне: для low-poly этого хватает,
а выборка из четырёхмегапиксельной картинки заметно медленнее. Правая кнопка по
карточке — выбрать другой файл.

### Узоры

Десять процедурных узоров: волокно, крап, кладка, крошка, полосы, клетка,
царапины, трава, потёки. Считаются формулой по координатам развёртки, а не
берутся картинками — узор не зависит от размера текстуры, ничего не грузится
с диска, и один тексель всегда даёт одно значение. Последнее важно: за мазок
тексель задевается десятки раз, и «случайный» узор мерцал бы.

Узор привязан к развёртке, а не к мазку: два прохода по одному месту дают тот
же рисунок, а не кашу из наложенных узоров. Второй цвет узора по умолчанию —
затемнение основного, так узор читается на любом цвете.

Пипетка берёт материал целиком — и цвет, и поверхность под курсором.

Сцене добавлена карта окружения. Она нужна ровно из-за металла: у
металлической поверхности нет диффузной составляющей, она видна только
отражением, и без окружения покрашенное железо выходит чёрным пятном.
Яркость окружения умеренная — инструмент про цвет. Режим показа «плоско»
по-прежнему даёт текстуру один в один, без всякого света.

### Окно материала

Кнопка в заголовке секции «Материал».

Окно в три колонки:

1. **Цвет** — квадрат насыщенность–яркость, полоса тона, поле HEX, альфа и
   **оттенки**: восемь ступеней текущего цвета от тени к свету. К свету цвет
   чуть блёкнет, к тени насыщается — так его видит глаз, и зоны low-poly
   собираются одним рядом.
2. **Чем красим** — шар выбранного материала на шахматке, чтобы прозрачность
   была видна, а не только написана процентами. Под ним поверхность: готовые
   наборы и ползунки шероховатости и металла. Шар отзывается на каждое
   движение.
3. **Библиотека материалов** — двенадцать групп, каждая раскрывается и
   сворачивается. Первой идёт **«Краска»**: обычные цвета без узора и блеска,
   самый частый случай. Дальше дерево, камень, кладка, металл, зелень, земля,
   вода, ткань, стекло, ржавчина, свет и тень. Материалы показаны **шарами** с
   их собственным узором, как в Blender и 3ds Max. Выбор ставит всё разом —
   цвет, узор, поверхность и прозрачность: иначе шар обещал бы одно, а модель
   показывала другое.

Во второй колонке к поверхности добавлены **прозрачность** и **узор** со
списком, масштабом и контрастом.

Внизу **ОК** и **Отмена**. Всё, что меняется в окне, сразу видно на шаре;
«Отмена», Esc и щелчок мимо окна возвращают материал к тому, что был до
открытия.

Шары считаются аналитически в обычном 2D-полотне, без второй сцены three.js:
у сферы нормаль известна из самой точки, поэтому освещение берётся формулой.
Металлу добавлено отражение студии — небо, светлая полоса горизонта и тёмный
пол: без него у металла нет диффузной составляющей и шар выходит чёрным.

**Слои:** видимость, непрозрачность, наложение (обычное, умножение, экран),
маска на слой. Структура слоёв общая для всех мешей модели — покраска уровня
не рассыпается на несвязанные стопки.

**История** — отдельная панель со списком шагов: можно не только шагнуть назад,
но и щёлкнуть любой шаг и оказаться в нём. Шаги впереди текущего показаны
приглушённо. Удаление слоя вычищает из истории его правки, чтобы она не
обещала шагов, которых уже нет.

**Развёртка** — панель на полэкрана (кнопка «Развёртка» или **U**), ширина
тянется за разделитель. В ней видно текстуру и сетку UV; кисть, ластик,
пипетка и заливки работают прямо по развёртке — щелчок заливки попадает в
грань под курсором. Удобно там, где на модели грань уходит из виду или слишком
мелкая.

**Развёртка** видна и в боковой панели — маленькая карта с сеткой UV, по
которой сразу понятно, куда легла краска и много ли пустого места на атласе.
Щелчок по ней открывает полноразмерный редактор.

**Панели** прячутся по отдельности (кнопки справа вверху) или разом по **Tab**.
Ширина правой панели и ширина развёртки тянутся за разделители. Состояние
секций, обе ширины и скрытые панели переживают перезагрузку.

## Управление видом

Всё, что относится к виду, живёт **поверх вьюпорта**, а не в боковой панели —
там же, куда смотришь.

- **Полоска значков** справа вверху: список видов, вписать в кадр,
  перспектива ↔ ортография, показ материал ↔ плоско, сетка пола.
- **Куб ориентации** под ней — как в 3ds Max: показывает, с какой стороны
  смотрит камера, и сам служит управлением.
  - **Протяжка** левой кнопкой — вращать камеру, будто взялись за куб рукой.
  - **Щелчок** без протяжки — встать на вид: по **грани** осевой, по **ребру**
    под 45°, по **углу** изометрия. Всего 26 направлений от одного куба.
- **Точка вращения** — три значка слева от полоски: **мир** (вокруг начала
  координат), **объект** (вокруг центра модели), **камера** (вокруг точки, на
  которую смотрим). Переключение **не двигает кадр**: меняется только то,
  вокруг чего крутится и приближается вид.

  Ради этого вращение и зум сделаны своими, а не оставлены OrbitControls: у
  него точка взгляда и точка вращения — одна и та же величина, и сменить
  вторую, не дёрнув первую, нельзя. Здесь вокруг выбранной точки поворачивается
  связка целиком — и камера, и точка взгляда, поэтому кадр остаётся
  осмысленным. За OrbitControls остался сдвиг вида.
- **Сетка модели** — отдельная кнопка в полоске: все рёбра плюс точки в
  вершинах, ровно то же, что показывает панель развёртки. Сразу видно,
  насколько мелко нарезана форма и докуда дотянется заливка по граням.

## Меню программы

Строка меню сверху повторяет всё, что есть на панелях, с подсказками клавиш:

| Меню | Что внутри |
|---|---|
| **Файл** | открыть GLB, демо-модель, сохранить PNG, размер текстуры |
| **Правка** | отменить, вернуть, к исходному состоянию, к последнему шагу |
| **Слой** | новый слой, маска, удалить, режим наложения |
| **Вид** | шесть видов и 3/4, ортография, вписать в кадр, показ, сетка пола |
| **Инструмент** | кисть, ластик, пипетка, три заливки, маска |
| **Панели** | развёртка, сетка развёртки, колонка инструментов, правая панель, скрыть всё |

Пункты-переключатели помечаются галочкой, взаимоисключающие — точкой,
недоступные гаснут (например, «Отменить», когда отменять нечего).

## Как устроено

```
src/
  main.js        состояние, связь панелей с вьюпортом, ввод
  viewport.js    сцена three.js, загрузка GLB, попадание луча
  painter.js     ЯДРО: проекция кисти на поверхность, мазок, заливки
  layers.js      слои, сборка итоговой текстуры, журнал отмены
  mesh-cache.js  предрасчёт по мешу: оболочки граней, смежность, наложения UV
  ui.js          палитра, список слоёв
  viewcube.js    куб ориентации: показывает ракурс и переключает вид
  menubar.js     строка меню, описанная данными
  modals.js      окна кистей и материалов, подбор цвета
  matball.js     шар материала: аналитическое освещение сферы
  patterns.js    процедурные узоры материала
electron/main.cjs   оболочка десктопного окна
electron-builder.yml  настройки установщика
scripts/make-icon.mjs значок приложения, рисуется кодом
  demo.js        демо-хижина с честным атласом
public/
  test-props.glb тестовый ассет из Blender (ящик + бочка, Smart UV Project)
```

**Кисть — это шар в пространстве модели, а не круг на текстуре.** Наивный
способ (взять UV под курсором и поставить кружок) на low-poly разваливается:
где развёртка растянута — растягивается и мазок, а на шве он обрывается.
Здесь для каждого треугольника, попавшего в шар, считаются его тексели, и для
каждого текселя восстанавливается точка на поверхности. Размер мазка одинаков
по всей модели, а шов проходится сам: по обе стороны шва лежат треугольники, и
оба попадают в шар.

**Полоса за краем треугольника** (`PAD`, два текселя) закрывает щели на швах:
тексель, который не достался никому, всё-таки красится соседним треугольником.
Точка поверхности для такого текселя берётся по **неприжатым** барицентрическим
координатам — по плоскости треугольника, продолженной за край. Прижимать точку
к самому треугольнику нельзя: прижатая точка ближе к центру кисти, чем
настоящая, и на каждом внутреннем ребре остаётся гребень лишней краски в три
текселя (замерено: 67 → 122 из 255). Глазом это читается как ступенчатый срез
мягкой кромки вдоль диагонали квада.

**Внутри одного прохода альфа текселя берётся по максимуму**, иначе медленное
ведение темнело бы: отпечаток ставится не реже одного на событие указателя, и
при задержке руки их десятки на одном месте. Но когда мазок возвращается на
собственный след, это уже второй проход, и краска должна лечь поверх — иначе
на перекрестье остаётся бледная звёздочка. Отличаются они по **пути**: если с
последнего касания кисть прошла больше своего поперечника, значит она успела
уйти и вернуться. Путь на тексель хранится квантами по восьмой радиуса.

**Промежутки между событиями мыши добиваются шагами по экрану**, с новым лучом
на каждом шаге. Интерполировать по прямой в пространстве нельзя: когда курсор
перескакивает с крыши на стену, прямая проходит сквозь объём дома и кисть мажет
изнутри, по дальним стенам.

**Скорость держится на двух вещах.** Первая — равномерная сетка по габариту
меша: кисть берёт кандидатов из ячеек, а не перебирает все треугольники модели
на каждый отпечаток. Вторая — перенос накопленного в текстуру **раз в кадр**, а
не на каждый отпечаток: за один взмах мыши их ставятся десятки, и каждая сборка
тянет перезаливку текстуры на видеокарту. На демо-хижине перенос занимает
десятые доли миллисекунды на кадр, и цифра видна в строке состояния.

## 🔴 Грабли: развёртка с наложением

Если две далёкие друг от друга грани делят одни и те же тексели, покрасить
модель по-человечески нельзя — мазок по одной стене проступит на другой, а
кисть вместо круга оставит обрезки. Так ведут себя коробки из примитивов
(`BoxGeometry`: все шесть граней в одном квадрате 0..1) и ассеты с зеркальной
развёрткой.

Инструмент считает долю наложения при загрузке и **предупреждает красным в
строке состояния**. Лечится в Blender: `smart_uv` или ручная развёртка.

## Не сделано

- **Возврат в проект и в GLB** — по решению владельца откладывался до
  прототипа. Прототип есть; формат надо выбрать.
- Сохранение и загрузка сессии покраски (слои, маски) — сейчас только выпечка
  PNG итоговой текстуры.
- Перетаскивание порядка слоёв, копирование слоя.
- Симметрия, мазок по прямой, стабилизация линии.
- В развёртке пока нет выделения островов и показа швов отдельным цветом.
- Фигуры и текст не учитывают перекрытие: отсекаются только отвёрнутые грани,
  но труба не отбрасывает «тень» на крышу за собой. Для этого нужен буфер
  глубины в экранном пространстве.
- Приложение не подписано и не заверено Apple: установщик собирается, но при
  первом запуске macOS спросит подтверждение.
