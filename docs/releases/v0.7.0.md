## New in 0.7.0

**AI painting over MCP, grown up.** Tested with live Claude Code runs on a
6953-triangle character painted from a reference sheet:

- **Geometry pieces.** `describe_model` lists the model's separate parts (a
  boot, a wristband, a belt loop, the rim and centre of a gem); the AI paints
  whole pieces along their own borders instead of slicing the model by height.
- **Point at the picture.** `fill_at` fills whatever is under pixels of a
  render; `dry_run` + `preview` shows the selection tinted before painting.
- **See the details.** Close-ups (`focus`) of an eye, a belt, a sole;
  `isolate` shows only chosen pieces, so surfaces hidden behind others (a
  jacket edge behind the trousers) can be seen and painted; a `turnaround`
  sheet puts front, side and back side by side like the reference.
- **Clean up.** `find_patches` finds small leftover patches and tells an
  intended detail from a leftover; `undo` reverts the AI's own steps only;
  wireframe, flat colour and whole-UV views.
- **Careful workflow.** The server tells the AI to start with an inventory of
  every detail of the reference and to finish by checking it item by item.

**Painting core.** Thin sliver triangles no longer keep their old colour
next to a fill. Dense models open with a 2048 texture automatically (a size
you choose yourself is kept). Paint materials are double-sided: through real
holes in clothing you see the inside of the fabric, not the background.

**Look.** New application icon; the start screen shows the version and the
name in the icon's colours.

## Новое в 0.7.0

**ИИ красит по MCP — всерьёз.** Проверено живыми прогонами Claude Code на
персонаже в 6953 треугольника, раскрашенном по листу референса:

- **Детали геометрии.** `describe_model` перечисляет отдельные части модели
  (ботинок, напульсник, шлёвку, оправу и центр камня); ИИ красит деталь
  целиком по её краю, а не режет модель по высоте.
- **Указать на картинке.** `fill_at` заливает то, что под пикселями снимка;
  `dry_run` + `preview` до покраски показывает выбор подсвеченным.
- **Видеть мелочи.** Крупные планы (`focus`) глаза, ремня, подошвы;
  `isolate` показывает только выбранные детали — видно и то, что закрыто
  другими (край куртки за джинсами); разворот `turnaround` — перёд, бок и
  спина рядом, как на листе референса.
- **Навести порядок.** `find_patches` находит мелкие недокрашенные пятна и
  отличает задуманную деталь от недокраса; `undo` отменяет только шаги ИИ;
  снимки с каркасом, «плоско» и вся развёртка.
- **Внимательная работа.** Сервер велит ИИ начинать с описи всех деталей
  референса и заканчивать проверкой по ней пункт за пунктом.

**Ядро покраски.** Узкие треугольники-щепки больше не остаются старого
цвета рядом с заливкой. Плотные модели открываются с текстурой 2048 сами
(выбранный вручную размер сохраняется). Материалы двусторонние: сквозь
настоящие дыры в одежде видна изнанка ткани, а не фон.

**Вид.** Новый значок программы; на начальном экране — версия и название в
цветах значка.

## First launch / Первый запуск

The apps are not signed. macOS: right-click the icon → Open → Open.
Windows: More info → Run anyway.

Приложение не подписано. macOS — правой кнопкой по значку → «Открыть» →
«Открыть». Windows — «Подробнее» → «Выполнить в любом случае».
