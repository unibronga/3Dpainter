Builds for macOS (`.dmg`, Apple Silicon) and Windows (`.exe`).
Сборки для macOS (`.dmg`, Apple Silicon) и Windows (`.exe`).

## Fixed in 1.0.3

**Saving into Downloads, Desktop or your home folder works.** Saves that
write several files into a folder (face with expressions, OBJ + MTL, PNG maps)
silently did nothing when you picked one of these folders: the desktop app
refused access without asking, and the picker just closed. Your own folders
are now allowed; a system folder gets an explanation and the picker opens
again.

**Long saves are visible.** The "Save as" dialog closes right away and the
busy indicator now shows above any dialog — before, a face export of a dense
model sat for seconds behind the dialog with a greyed-out button.

## Исправлено в 1.0.3

**Сохранение в «Загрузки», на «Рабочий стол» и в домашнюю папку работает.**
Сохранения набором в папку (лицо с выражениями, OBJ + MTL, карты PNG) молча
ничего не делали, если выбрать одну из этих папок: приложение отказывало в
доступе без вопроса, и окно выбора просто закрывалось. Теперь свои папки
разрешены; на системную программа объяснит и откроет выбор снова.

**Долгое сохранение видно.** Окно «Сохранить как» закрывается сразу, а
индикатор занятости показывается поверх любых окон — раньше выгрузка лица
плотной модели секундами стояла за окном с погашенной кнопкой.
