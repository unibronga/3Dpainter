Сборки для macOS (`.dmg`, Apple Silicon) и Windows (`.exe`).

## New in 1.1.0

**Painting from LevelMaker in one click.** LevelMaker (the level editor of
ELTARAX) opens a model straight in 3DPainter with a small job file
(`<name>.levelmaker.json`): no start screen, no dragging. A **From LevelMaker**
bar shows above the view; **Save and return to LevelMaker** writes the painted
GLB (and face atlases, and the project) where LevelMaker expects it — no
dialogs — and switches back. Contract `levelmaker-paint/1`: atomic writes,
a status file (`opened` / `saved` / `cancelled` / `failed`).

**One window only.** Launching 3DPainter again (Windows does it on every
"Paint" click) hands the file to the window that is already open.

**Unsaved work is asked about** before a LevelMaker job replaces it:
Save / Don't save / Cancel.

## Новое в 1.1.0

**Покраска из LevelMaker в один щелчок.** LevelMaker (редактор уровней
ELTARAX) открывает модель прямо в 3DPainter маленьким файлом задания
(`<имя>.levelmaker.json`): без начального экрана и перетаскивания. Над видом —
полоса **«Из LevelMaker»**; **«Сохранить и вернуть в LevelMaker»** пишет
покрашенный GLB (и атласы лица, и проект) туда, где его ждёт LevelMaker, —
без окон — и возвращает в него. Договор `levelmaker-paint/1`: атомарная
запись, файл состояния (`opened` / `saved` / `cancelled` / `failed`).

**Одно окно.** Повторный запуск 3DPainter (Windows делает его на каждый
«Разукрасить») передаёт файл в уже открытое окно.

**О несохранённой работе спрашивают**, прежде чем задание LevelMaker её
заменит: «Сохранить / Не сохранять / Отмена».
