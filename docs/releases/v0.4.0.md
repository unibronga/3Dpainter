Builds for macOS (`.dmg`, Apple Silicon) and Windows (`.exe`).
Сборки для macOS (`.dmg`, Apple Silicon) и Windows (`.exe`).

## New in 0.4.0

- **Lasso selection** — freehand (L) and polygonal (L again), as in Photoshop.
  While a selection exists, every tool paints only inside it. Shift adds,
  Alt subtracts, Shift+Alt intersects; ⌘A / ⌘D / ⇧⌘I in the new **Select** menu.
  Works on the model and in the UV editor; the edge shows as marching ants.
- **Interface scale** (File ▸ Settings, 80–200%) — text, icons, panels and
  dialogs grow together for large screens; the model and the UV map stay sharp.
- **Tooltips** on every button and control: name, shortcut and what it does.
- **Rotation step** for the orbit tool — tick it, set e.g. 30°, and the view
  turns in exact steps; plus a **reset view** button.
- **View to PNG** — the model exactly as framed in the viewport, on a
  transparent background, with a choice of size and edge smoothing.
- The small **PNG** button under the UV list saves just the open UV map.
- The tool column is regrouped; the mask brush is removed for now.
- Fixes: tools that do not paint (select, pan, orbit, zoom) no longer paint in
  the UV editor; no stray horizontal scrollbar in the material dialog.

## Новое в 0.4.0

- **Выделение лассо** — вольное (L) и по точкам (L ещё раз), как в Photoshop.
  Пока выделение есть, любой инструмент красит только внутри. Shift добавляет,
  Alt вычитает, Shift+Alt — пересечение; ⌘A / ⌘D / ⇧⌘I в новом меню
  **Выделение**. Работает на модели и в развёртке, край — бегущий пунктир.
- **Масштаб интерфейса** (Файл ▸ Настройки, 80–200%) — текст, значки, панели
  и окна растут разом; модель и развёртка остаются чёткими.
- **Подсказки** у каждой кнопки и элемента: название, клавиша, что делает.
- **Шаг поворота** у вращения — поставил галочку и 30°, и вид поворачивается
  ровно по шагам; и кнопка **сброс вида**.
- **Вид в PNG** — модель в ракурсе вьюпорта на прозрачном фоне, размер и
  сглаживание края на выбор.
- Маленькая кнопка **PNG** под списком развёрток сохраняет только открытую.
- Колонка инструментов перегруппирована; кисть по маске пока убрана.
- Исправлено: выбор объекта и инструменты вида больше не красят в развёртке;
  нет лишней горизонтальной прокрутки в окне материала.

## First launch / Первый запуск

The apps are not signed. macOS: right-click the icon → Open → Open.
Windows: More info → Run anyway.

Приложение не подписано. macOS — правой кнопкой по значку → «Открыть» →
«Открыть». Windows — «Подробнее» → «Выполнить в любом случае».
