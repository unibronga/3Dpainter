Builds for macOS (`.dmg`, Apple Silicon) and Windows (`.exe`).
Сборки для macOS (`.dmg`, Apple Silicon) и Windows (`.exe`).

## New in 1.1.1

**You can see what was saved.** Every save — GLB, OBJ and maps as a folder,
project, view PNG, face — ends with a **Saved** card: the file or folder name,
where it is and how many files. In the desktop app the card has
**Show in Finder** (Explorer on Windows). A failed save shows a red card with a
plain reason, such as no permission to write to the folder.

**System save dialogs in the desktop app**, opening where you saved last time.

## Новое в 1.1.1

**Видно, что сохранилось.** Каждое сохранение — GLB, OBJ и карты папкой,
проект, вид в PNG, лицо — заканчивается плашкой **«Сохранено»**: имя файла или
папки, где лежит и сколько файлов. В приложении на ней кнопка
**«Показать в Finder»** (в Проводнике на Windows). Не вышло — красная плашка с
понятной причиной, например нет прав на запись в папку.

**Системные окна сохранения в приложении** — открываются там, где сохраняли в
прошлый раз.
