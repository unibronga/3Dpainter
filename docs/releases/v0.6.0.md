Builds for macOS (`.dmg`, Apple Silicon) and Windows (`.exe`).
Сборки для macOS (`.dmg`, Apple Silicon) и Windows (`.exe`).

## New in 0.6.0

- **Effects menu.** Changes how the model is shown, not the paint: maps,
  layers and saved files stay as they are. The brush ring and floor grid stay
  sharp, so you can keep painting with an effect on, and **View to PNG**
  captures the image with the effect.
  - **Pixel art** — large square pixels, an optional reduced palette and a
    dark outline around the silhouette.
  - **Anime** — cel shading in the spirit of Genshin Impact: stepped light
    with a crisp, cool-tinted shadow, ink lines along silhouettes and creases,
    and a bright rim along the edges.
- **AI painting over MCP** (desktop app only, off by default). Turn it on in
  Settings, run the `claude mcp add …` line it shows, and Claude Code — or any
  other MCP client — can paint the open model from a prompt: describe its
  parts, fill them with colours and surfaces on its own layer, render views
  to check the result and save the project. The server listens on
  `127.0.0.1` only and requires a key; every AI fill is an ordinary undo step.

## Новое в 0.6.0

- **Меню «Эффекты».** Меняет то, как модель показана, а не покраску: карты,
  слои и сохранённые файлы остаются прежними. Кольцо кисти и сетка пола
  остаются тонкими — красить с эффектом можно, а **Вид в PNG** снимает
  картинку с эффектом.
  - **Пиксель-арт** — крупные квадратные пиксели, урезанная палитра и тёмный
    контур по силуэту на выбор.
  - **Аниме** — cel-shading в духе Genshin Impact: свет ступенями с резкой
    прохладной тенью, чернильная линия по силуэту и сгибам, светлая кромка.
- **ИИ красит модель по MCP** (только в приложении, по умолчанию выключено).
  Включите в Настройках, выполните показанную там строку `claude mcp add …` —
  и Claude Code или другой клиент MCP раскрасит открытую модель по словесной
  задаче: изучит части, зальёт их цветом и поверхностью на своём слое, снимет
  виды для проверки и сохранит проект. Сервер слушает только `127.0.0.1` и
  пускает по ключу; каждая заливка ИИ — обычный шаг отмены.

## First launch / Первый запуск

The apps are not signed. macOS: right-click the icon → Open → Open.
Windows: More info → Run anyway.

Приложение не подписано. macOS — правой кнопкой по значку → «Открыть» →
«Открыть». Windows — «Подробнее» → «Выполнить в любом случае».
