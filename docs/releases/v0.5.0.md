Builds for macOS (`.dmg`, Apple Silicon) and Windows (`.exe`).
Сборки для macOS (`.dmg`, Apple Silicon) и Windows (`.exe`).

## New in 0.5.0

- **Project files `.3dpaint`** — File ▸ Save project (Cmd+S) keeps the whole
  session like a PSD: every layer with its colour, roughness, metalness and
  transparency maps, layer settings, model orientation, camera, material and
  brush. The first Cmd+S asks where; the next ones overwrite silently.
- **Saved models reopen with their paint.** GLB, or OBJ with its `.mtl` and
  `.png`: the map goes into the first layer and you keep painting. Maps of
  models from other programs are picked up too.
- **Multi-file saves go into one folder** (OBJ + MTL + PNG, all maps): one
  question where to save instead of a dialog per file.
- **Model orientation.** A model always stands on the floor at the origin;
  “This is the front” / “This is the top” set where it faces, remembered per
  model. Exports keep the original coordinates.
- **Recent files keep `.mtl` and textures**, so OBJ models reopen in colour.
- **About** window and **five more languages**: German, Spanish, French,
  Dutch and Ukrainian.
- Fixes: GLB export wrote the paint map flipped (paint showed on the wrong
  faces in other viewers — re-export files saved with earlier versions); the
  start screen stayed open after “Open a model”; a flash of unstyled page on
  startup.

## Новое в 0.5.0

- **Свой формат проекта `.3dpaint`** — Файл ▸ Сохранить проект (Cmd+S)
  сохраняет работу целиком, как PSD: все слои с картами цвета, шероховатости,
  металла и прозрачности, свойства слоёв, положение модели, ракурс, материал
  и кисть. Первый Cmd+S спрашивает место, следующие пишут молча.
- **Сохранённая модель открывается с покраской.** GLB или OBJ вместе с
  `.mtl` и `.png`: карта ложится в первый слой, красить можно дальше. Карты
  моделей из других программ тоже подхватываются.
- **Несколько файлов сохраняются в одну папку** (OBJ + MTL + PNG, все карты):
  один вопрос о месте вместо окна на каждый файл.
- **Положение модели.** Модель всегда встаёт на пол в центр; «Это перед» и
  «Это верх» задают, куда она смотрит, — запоминается для каждой модели.
  В файл модель уходит в исходных координатах.
- **Недавние хранят `.mtl` и текстуры** — OBJ открывается в цвете.
- Окно **«О программе»** и **ещё пять языков**: немецкий, испанский,
  французский, нидерландский, украинский.
- Исправлено: экспорт GLB писал карту перевёрнутой (в других программах
  покраска ложилась не на те грани — пересохраните файлы из прежних версий);
  начальный экран не закрывался после «Открыть модель»; вспышка страницы без
  стилей при запуске.

## First launch / Первый запуск

The apps are not signed. macOS: right-click the icon → Open → Open.
Windows: More info → Run anyway.

Приложение не подписано. macOS — правой кнопкой по значку → «Открыть» →
«Открыть». Windows — «Подробнее» → «Выполнить в любом случае».
